# Agent Rules for ccc-forensic-demo

- **Git Commits**: When committing changes to the repository, you must always run `git push origin main` (or the equivalent remote branch) immediately after committing. Do not leave commits sitting locally, as the project relies on remote push for deployments (e.g. Render, Netlify).

- **Git Commits**: Whenever we make changes, commit them locally but DO NOT push everything to the remote (origin main) until the user explicitly gives the command to do so. This supersedes the global push rule.
